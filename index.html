Dokumentasi 2 Kerentanan Terencana (Untuk Dosen)

1. SQL Injection (Bypass Otentikasi Login)

Lokasi: Form Login Utama.

Mekanisme Kerentanan: Query SQL backend merangkai input pengguna secara mentah tanpa sanitasi atau Prepared Statements:

SELECT * FROM akun_pengguna WHERE id_user = '${username}' AND kata_sandi = '${password}'

Cara Pengujian:
Ketik username: admin' OR '1'='1 atau cukup klik tombol ⚡ Eksploit SQL Injection. Karena klausa '1'='1' selalu bernilai TRUE, server akan membypass verifikasi password dan langsung meloloskan sesi sebagai akun berhak tertinggi (Superadmin)!

2. Stored Cross-Site Scripting (Stored XSS)

Lokasi: Forum Diskusi Kampus.

Mekanisme Kerentanan: Pesan yang dikirim pengguna disimpan ke database lokal dan dirender kembali menggunakan properti element.innerHTML = pesan tanpa encoding karakter khusus HTML (seperti <, >, ").

Cara Pengujian:
Kirimkan komentar berupa script:
<img src=x onerror="alert('Celah Stored XSS Berhasil Ditembus!')">
Script akan tersimpan secara permanen dan otomatis dieksekusi di browser siapa pun yang membuka tab Forum Diskusi.

3. Kerentanan Tambahan: Validasi Berkas Lemah (Unrestricted Upload)

Lokasi: Form Unggah Tugas Mahasiswa.

Mekanisme Kerentanan: Sistem tidak membatasi ekstensi file yang diunggah (tidak ada whitelist .pdf atau .docx), sehingga berkas berbahaya (seperti skrip executable) dapat terunggah ke sistem.
