Dokumentasi 2 Kerentanan Yang Dibuat Sengaja

1. SQL Injection (Bypass Otentikasi Login)

Lokasi: Form Login Utama.

Mekanisme: Nilai masukan digabungkan langsung ke string query tanpa sanitasi atau parameterisasi (Prepared Statements):
SELECT * FROM users WHERE username = '${username}' AND password = '${password}'

Cara Membuktikan (Eksploit):
Ketik username: admin' OR '1'='1 atau cukup klik tombol merah ⚡ Eksploit SQL Injection di halaman login. Sistem akan bypass password dan langsung login sebagai akun pertama di database (Administrator)!

2. Stored Cross-Site Scripting (Stored XSS)

Lokasi: Tab Forum Diskusi Akademik.

Mekanisme: Komentar forum disimpan ke memori/penyimpanan dan ditampilkan kembali menggunakan properti element.innerHTML = pesan tanpa encoding HTML (seperti htmlspecialchars).

Cara Membuktikan (Eksploit):
Ketik pesan forum: <img src=x onerror="alert('Celah Stored XSS Terbuka!')">
Pesan akan tersimpan dan script akan langsung tereksekusi pada setiap pengguna yang membuka tab Forum Diskusi!

3. Kerentanan Tambahan: Validasi Berkas Lemah (Unrestricted Upload)

Lokasi: Form Unggah Tugas Mahasiswa.

Mekanisme: Form tidak membatasi tipe ekstensi berkas (whitelist), sehingga file berekstensi berbahaya (misal .php, .html) dapat terunggah ke sistem.
